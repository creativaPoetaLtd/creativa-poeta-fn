## Role de cette page

Cette page est un outil d'entree. Elle doit attirer les visiteurs, leur faire prendre conscience d'un probleme, puis les transformer en leads.

Elle parle a deux publics:

- ceux qui ont deja un site.
- ceux qui n'ont pas encore de site mais ont des profils Google Maps, reseaux sociaux ou WhatsApp.

## Ce que l'audit verifie

Titre:

```text
Ce que nous regardons
```

Texte:

```text
L'objectif n'est pas de juger votre entreprise. L'objectif est de voir si vos informations sont faciles a trouver, coherentes et suffisamment claires pour les clients comme pour les moteurs modernes.
```

Points analyses:

### Votre presence officielle

```text
Nous regardons si votre entreprise a une base claire: site, page officielle ou profil principal.
```

### Vos informations essentielles

```text
Nous verifions si le nom, les services, le pays, la langue, les contacts, les horaires et les zones desservies sont faciles a comprendre.
```

### Votre lisibilite par les moteurs

```text
Nous observons si les informations importantes sont disponibles clairement, sans etre cachees ou dispersees.
```

### Vos profils locaux

```text
Nous regardons si Google, Apple, Bing ou les cartes peuvent s'appuyer sur des informations coherentes.
```

### Vos reponses aux questions clients

```text
Nous verifions si votre presence repond aux questions simples que vos clients posent avant de vous contacter.
```

## Score V1

Scores proposes:

- visibilite globale.
- clarte de l'offre.
- coherence des informations.
- presence locale.
- qualite des reponses.
- base technique.

Niveaux:

```text
0-3: difficile a comprendre
4-6: visible mais incomplet
7-8: bonne base
9-10: tres bonne base
```

## Resultat affiche

Titre:

```text

```

Texte selon score bas:

```text
Votre presence contient des informations utiles, mais elles ne sont pas encore assez claires ou assez coherentes pour aider les moteurs modernes a vous recommander facilement.
```

Texte selon score moyen:

```text
Votre entreprise a deja une base visible, mais certains elements peuvent etre ameliores pour mieux guider Google, les cartes et les moteurs IA.
```

Texte selon score haut:

```text
Votre presence est deja bien structuree. Les prochaines ameliorations doivent viser la coherence, les reponses aux questions clients et l'expansion locale ou multilingue.
```

CTA resultat:

```text
Recevoir un plan d'amelioration
```

## Pourquoi cet audit est utile

Titre:

```text
Les clients cherchent autrement.
```

Texte:

```text
Un client peut chercher un service sur Google, demander une recommandation a Siri, comparer des options dans une carte, poser une question a ChatGPT ou verifier votre activite sur Instagram.

Si vos informations ne sont pas coherentes, les moteurs peuvent hesiter. Si elles sont claires et bien reliees, votre entreprise devient plus facile a comprendre.
```

## Ce que l'audit ne promet pas

Texte:

```text
Cet audit ne garantit pas une premiere position sur Google ni une recommandation automatique par une IA. Il identifie les fondations qui aident votre entreprise a etre mieux comprise et plus facilement trouvee.
```

## Notes internes V1

L'audit V1 peut commencer sans IA avancee.

Signaux detectables automatiquement:

- URL disponible.
- titre de page.
- description.
- presence d'un formulaire ou contact.
- presence d'adresse, telephone, email.
- liens vers reseaux sociaux.
- presence d'un fichier robots.
- presence d'un plan du site.
- poids approximatif de la page.
- texte principal disponible dans le HTML.

Signaux a demander dans le formulaire:

- pays cible.
- langue principale.
- type d'entreprise.
- presence Google Maps.
- presence Instagram/Facebook/LinkedIn.

Version V2:

- generation automatique d'un mini-rapport.
- recommandations personnalisees.
- sauvegarde du lead en base.
- notification email interne.
- scoring par marche.
